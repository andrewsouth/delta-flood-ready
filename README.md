# Delta Flood Ready Toolkit

Illustrative mockups for a rural flood early-warning pilot in Delta, Utah: the tools, spaces, and places where the work happens, a flow diagram of how the pieces connect, and mockups of the public brief, map, program website, and library disaster corner.

All flows, dates, percentages, and map zones are invented for the design and are not a real forecast.

Live page: https://andrewsouth.github.io/delta-flood-ready/
